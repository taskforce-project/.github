## Vision

Taskforce construit une plateforme ERP premium pour piloter projets, ressources et operations sur une base technique fiable, securisee et evolutive.

## Focus Produit

- ERP modulaire (core et extensions)
- API backend securisee et documentee
- Frontend metier pour les operations quotidiennes
- Landing page orientee acquisition et marque
- Workflow engineering avec tests, CI et observabilite

## Stack

- Backend: Java 21, Spring Boot
- Frontend: Next.js, TypeScript, Tailwind CSS
- Landing: Astro
- IAM: Keycloak
- Data: PostgreSQL
- Delivery: Docker, GitHub Actions
